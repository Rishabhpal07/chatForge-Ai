# @chatforge/widget

Embeddable chat widget. Built to a single `dist/widget.js` (IIFE) that mounts a
chat panel inside a Shadow DOM on the host page.

Embed snippet:

```html
<script src="https://cdn.chatforge.ai/widget.js" data-bot="pk_live_xxx" async></script>
```

Implementation lands in milestone **M3** (see `docs/` plan). This package is scaffolded
now so the npm workspace resolves.
